# 🐟 Goofish Monitor Bot — Полная инструкция

Телеграм-бот для мониторинга объявлений на **Goofish (闲鱼)** с переводом с китайского и AI-поиском по фото.

---

## ✨ Возможности

| Функция | Описание |
|---|---|
| 🏷 Мульти-тег поиск | `rick owens, rickowens, ro` → один поиск |
| 💰 Фильтр по цене | Минимальная и максимальная цена в ¥ |
| 🇨🇳→🇷🇺 Автоперевод | Название и описание на русском |
| 🖼 AI-поиск по фото | Найди похожие вещи по своей фотке |
| 🔔 Уведомления | Только новые объявления, без дублей |
| ⏱ Интервал | Настраиваемый: 10 мин / 30 мин / 1 час / 3 часа |
| 👥 Мульти-пользователь | До 5 друзей с отдельными поисками |

## 🚀 Деплой на Railway (бесплатно)

### Шаг 1 — Создать бота в Telegram

1. Открой Telegram, найди **@BotFather**
2. Отправь `/newbot`
3. Придумай имя и username для бота
4. Скопируй **токен** — он выглядит так: `1234567890:AAFxxxxxxxxxxxxxxxx`

---

### Шаг 2 — Узнать свой Telegram ID

1. Найди в Telegram бота **@userinfobot**
2. Напиши ему `/start`
3. Он пришлёт твой ID (число вида `123456789`)
4. Запомни его — понадобится для настройки

---

### Шаг 3 — Получить Cookie с Goofish ⚡

Это самый важный шаг — без него поиск будет ограничен.

**На компьютере:**
1. Открой браузер Chrome/Firefox
2. Зайди на **https://www.goofish.com**
3. Войди в свой аккаунт (через Alipay)
4. Нажми `F12` → вкладка **Network (Сеть)**
5. Обнови страницу (F5)
6. В списке запросов кликни на любой запрос к `goofish.com`
7. В правой панели найди раздел **Request Headers**
8. Найди строку `Cookie:` — скопируй всё значение (длинная строка)

Пример того, что ты копируешь:
```
_m_h5_tk=abc123_1234567890; cna=xxx; cookie2=yyy; ...
```

---

### Шаг 4 — Залить на Railway

1. Зайди на **https://railway.app**
2. Нажми **Sign Up → Continue with GitHub** (нужен GitHub аккаунт)
3. Нажми **New Project → Deploy from GitHub repo**
4. Создай новый репозиторий с файлами бота (или загрузи ZIP)

**Если нет GitHub-опыта — проще через zip:**
1. Скачай все файлы из этой папки
2. Зайди на https://github.com → New repository → назови `goofish-bot`
3. Нажми `uploading an existing file` → перетащи все файлы → Commit

5. В Railway выбери созданный репозиторий
6. Railway сам определит что это Python-проект

---

### Шаг 5 — Настроить переменные окружения

В Railway после создания проекта:
1. Нажми на сервис → вкладка **Variables**
2. Добавь переменные (нажимай **+ New Variable**):

| Имя | Значение |
|---|---|
| `BOT_TOKEN` | Токен от BotFather |
| `GOOFISH_COOKIE` | Cookie из шага 3 |
| `ALLOWED_USERS` | Твой Telegram ID (и друзей через запятую) |
| `CNY_TO_RUB` | Курс юань→рубль (например `13.5`) |

3. Нажми **Deploy** — Railway запустит бота

---

### Шаг 6 — Установить CLIP для поиска по фото

В Railway → вкладка **Settings → Build Command** добавь:

```
pip install -r requirements.txt && pip install git+https://github.com/openai/CLIP.git torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

> ⚠️ CLIP весит ~500MB. На бесплатном Railway может быть медленно при старте, но потом работает нормально.

## 💻 Локальный запуск (альтернатива Railway)

Если хочешь запустить на своём компьютере:

```bash
# 1. Установи Python 3.11+ с https://python.org

# 2. Скопируй .env.example в .env и заполни
cp .env.example .env

# 3. Установи зависимости
pip install -r requirements.txt
pip install git+https://github.com/openai/CLIP.git
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# 4. Запусти бота
python bot.py
```

> Чтобы бот работал постоянно на Windows: можно использовать **NSSM** или просто не закрывать терминал.

## 📱 Как пользоваться

### Добавить друзей
1. Они пишут боту `/start`
2. Узнают свой ID через @userinfobot  
3. Ты добавляешь их ID в `ALLOWED_USERS` через запятую: `123456,789012`
4. Перезапускаешь бота (в Railway → Redeploy)

### Создать поиск
1. Нажми **➕ Новый поиск**
2. Введи название (для себя)
3. Введи теги через запятую:
   - `rick owens, rickowens, ro drkshdw, 瑞克欧文斯`
   - Бот будет искать по каждому тегу и объединять результаты
4. Укажи диапазон цен в юанях (или 0 чтобы пропустить)
5. Выбери интервал проверки
6. Опционально — отправь фото для AI-поиска похожих

### Поиск по фото
1. Нажми **🖼 Найти по фото**
2. Отправь чёткое фото вещи
3. Бот найдёт визуально похожие объявления на Goofish

## 🔧 Типичные проблемы

**Бот не отвечает**
→ Проверь `BOT_TOKEN` в переменных Railway

**Нет объявлений**
→ Проверь `GOOFISH_COOKIE` — возможно истёк, обнови по шагу 3

**Перевод не работает**
→ Нормально, Google Translate иногда блокирует. Бот покажет оригинал.

**Поиск по фото не работает**
→ CLIP не установлен. Проверь Build Command в Railway.
